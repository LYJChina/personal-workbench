# LYJ Workbench 跨平台微内核路线图

本路线图把已确认的整体规格拆成五个可独立验收的实施计划。每个计划完成后，应用都必须可以启动和回滚；不得并行修改同一数据库迁移或应用装配文件。

## Plan 1：跨平台基础与提醒收缩

文件：`2026-08-23-cross-platform-foundation.md`

交付：Windows/macOS 统一启动、跨平台数据目录、单文件资料、主密码保险箱、旧 DPAPI 迁移、保留 SMTP 和手动邮件、移除自动定时发送及 PowerShell/VBScript 日常依赖。

## Plan 2：微内核与系统插件协议

交付：插件清单、贡献注册表、可撤销生命周期、依赖注入、系统插件加载、安全模式和现有 AI 模块的第一批迁移。

前置：Plan 1 完成。

## Plan 3：第三方文件夹插件与隔离运行

交付：文件夹导入、规范化安装包入库、兼容性校验、权限审批、iframe SDK、内容安全策略、声明式工作流、更新回滚和示例插件。

前置：Plan 2 完成。

## Plan 4：插件存储治理

交付：插件私有 CRUD、共享数据权限、分类配额、历史与缓存清理、附件限制、空间明细、数据导出和数据库压缩。

前置：Plan 3 完成。

## Plan 5：AI 用量与费用中心

交付：统一 AI 网关计量、Token 和缓存统计、价格版本、预计费用、按插件与模型聚合、90 天明细保留、长期每日汇总和预算提醒。

前置：Plan 2 完成；可以在 Plan 4 后执行，避免同时修改插件管理页面和数据库治理代码。

## 明确延期

- 飞书 Agent 双向通讯插件。
- Agent 运行时、会话协议和通讯渠道协议。
- 可信开发者模式下的任意 Node.js 插件。
- 自动触发提醒或后台计划任务。
