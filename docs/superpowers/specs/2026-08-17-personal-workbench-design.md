# 个人工作台设计说明

更新时间：2026-08-17  
状态：第一版设计已确认，可继续制定实施计划

## 1. 项目目标

搭建一套仅在个人 Windows 电脑上运行的本地数字工作台，用于集中管理个人资料、日常办公工具、提醒和后续扩展模块。

工作台采用模块化卡片结构。左侧导航和右侧内容区域均可扩展，并提供“编辑工作台”模式，让用户直接调整导航、卡片位置和尺寸。

## 2. 核心原则

- 完全本地运行，不部署到云端。
- 业务数据保存在本地数据库中。
- DeepSeek API Key 等敏感信息不得出现在前端代码、浏览器存储或普通业务表中。
- 第一版保持小而完整，先搭好扩展框架，再逐步增加模块。
- 每个功能是边界清晰的独立模块，新增模块不应破坏已有功能。

## 3. 第一版范围

### 3.1 我的主页

主页展示个人信息卡，支持维护：

- 姓名
- 生日
- 证件照
- 员工编号
- 用户自定义字段

个人信息可编辑并保存在本地数据库。证件照保存在本地应用数据目录，数据库只保存受控的文件引用。

### 3.2 AI 办公

“AI 办公”是左侧侧边栏中的一级模块入口，不直接把具体工具平铺在侧边栏中。

页面层级：

1. 点击侧边栏中的“AI 办公”。
2. 进入 AI 工具中心。
3. 工具中心用小卡片展示可用工具。
4. 第一版只有“日报填写”卡片。
5. 点击卡片后进入独立的日报填写功能页。

后续增加邮件撰写、内容总结等工具时，只需在 AI 工具中心注册新卡片。

### 3.3 日报填写

日报填写页包含两个输入区：

- 今日完成
- 问题与风险

处理流程：

1. 用户输入关键词、短句或零散描述。
2. 本地后台读取日报专用系统提示词。
3. 后台把系统提示词和用户输入发送给 DeepSeek。
4. DeepSeek 返回结构清晰、措辞专业的润色结果。
5. 页面展示生成结果。
6. 用户可以一键复制全文。
7. 输入、输出、生成时间和模型信息自动保存到本地日报历史。

生成结果保持“今日完成 / 问题与风险”两段结构。数据结构允许以后增加“明日计划”等字段。

第一版使用内置日报系统提示词。后续可增加提示词编辑和版本管理功能。

### 3.4 设置

设置页至少包含：

- DeepSeek API 地址
- 模型名称
- API Key 的录入、更新和连接测试
- 邮件发送配置
- 基础主题切换

API 请求必须由本地后台发出，浏览器页面不得直接携带 API Key 请求 DeepSeek。

API Key 应使用 Windows Credential Manager 或 Windows DPAPI 加密保存。设置页只显示掩码和“已配置”状态，不回显完整 Key。

### 3.5 外勤打卡邮件提醒

- 每周一自动发送“提交外勤打卡”邮件提醒。
- 工作台网页未打开时仍应正常执行。
- 使用 Windows 任务计划程序启动本地提醒任务。
- 第一版使用邮件通知，并为后续企业微信通知预留通知渠道接口。
- 提醒时间、收件地址和邮件发送配置在设置页维护。

## 4. 页面与导航结构

左侧侧边栏第一版建议包含：

- 我的主页
- AI 办公
- 提醒
- 密码保险箱（仅显示“即将推出”入口）
- 设置
- 编辑侧边栏入口

“AI 办公”使用比普通菜单更醒目的大入口样式，并带简短说明。侧边栏的数据结构支持后续新增分组、调整顺序、隐藏和固定入口。

右侧内容区域采用卡片式网格。第一版主页主要显示个人信息卡；AI 日报在独立的 AI 办公层级中使用，不强制平铺到主页。

## 5. 编辑工作台

用户可进入专门的编辑模式：

- 拖拽调整卡片位置
- 调整卡片尺寸
- 添加或移除允许配置的卡片
- 调整侧边栏入口顺序
- 隐藏或恢复侧边栏入口
- 保存当前布局

退出编辑模式后锁定布局，避免日常操作时误拖动。布局配置保存在本地数据库。

第一版只需支持已有模块的布局调整，不实现第三方插件安装系统。

## 6. 主题换肤

第一版提供基础浅色与深色主题，并保证侧边栏、卡片、按钮、表单和字体颜色同步变化。

主题选择保存在本地。主题系统使用设计变量实现，便于以后增加自定义配色、背景和更多皮肤。

## 7. 本地技术架构

推荐采用“本地 Web 工作台 + 本地后台服务 + SQLite + Windows 任务计划程序”：

- 前端：呈现卡片、编辑模式、表单和历史记录。
- 本地后台：提供数据接口、调用 DeepSeek、处理文件、发送邮件。
- SQLite：保存个人资料、日报、布局、提醒和普通设置。
- Windows 安全存储：保存 API Key 和邮件凭据。
- Windows 任务计划程序：保证工作台关闭时仍能执行每周提醒。

各模块通过稳定接口连接，避免页面直接访问数据库、系统凭据或第三方 API。

## 8. 建议的数据模块

- `profile`：个人基础信息。
- `profile_custom_fields`：个人自定义字段。
- `daily_reports`：日报原始输入、生成结果、时间和模型信息。
- `dashboard_layouts`：卡片位置、尺寸和启用状态。
- `navigation_items`：侧边栏分组、顺序和显示状态。
- `reminders`：提醒规则、渠道和启用状态。
- `app_settings`：非敏感设置，如主题、模型名称和 API 地址。
- 系统安全存储：API Key、SMTP 密码等敏感凭据，不进入普通 SQLite 表。

## 9. 异常与安全处理

- DeepSeek 未配置时，日报页明确引导用户前往设置。
- API 请求失败时保留用户输入，并显示可重试的错误提示。
- 复制成功或失败都要给出明确反馈。
- 日报历史写入失败时不得误报“已保存”。
- 邮件发送失败应记录本地日志，避免无限频繁重试。
- 用户上传的证件照只允许安全的图片格式，并限制文件大小。
- 页面、日志和导出文件不得记录完整 API Key 或邮件密码。
- 密码保险箱后续必须单独设计并进行加密安全评审。第一版只保留标记为“即将推出”的入口，不提供录入、保存、查看或解锁能力。

## 10. 第一版验收标准

- 应用能在个人 Windows 电脑本地启动，不依赖云端数据库。
- 个人信息可以新增、修改并在重启后保留。
- 证件照可以安全地选择、更换和显示。
- 可在设置页配置 DeepSeek，且页面不会回显完整 API Key。
- 日报页可提交两个字段，并得到保持对应结构的润色结果。
- 生成结果可以一键复制，日报历史可以按日期查看和再次编辑。
- 每周一在页面关闭时仍能发送外勤打卡提醒邮件。
- 密码保险箱入口可见并明确标记为“即将推出”，且不能录入或保存密码。
- 侧边栏和右侧卡片结构允许扩展。
- 编辑模式可以保存卡片布局。
- 浅色和深色主题均可正常使用。

## 11. 后续扩展方向

- 企业微信提醒渠道
- 更多 AI 办公工具卡
- 自定义日报模板和提示词
- 常用文件中心
- 常用网址卡片
- 待办事项和更多提醒规则
- 数据备份、恢复和迁移
- 经独立安全设计后的本地加密密码保险箱
- 用户自建文本卡、链接卡和文件卡

## 12. 当前不做

- 云端部署或云端同步
- 多用户与登录系统
- 第三方插件市场
- 密码保险箱的录入、保存、查看和解锁功能（第一版仅保留入口）
- 大量预置办公工具
